# reservation-system

お掃除の家事代行・片付けコンサル向け、LINE公式アカウント連携の予約システム。

## ドキュメント

- [要件定義書](docs/requirements.md)

## 概要

| 項目 | 内容 |
|---|---|
| 顧客インターフェース | LINE公式アカウント（リッチメニュー + LIFF） |
| 提供機能（顧客） | 予約・変更・キャンセル、定期利用の登録／変更／スキップ／解約、予約履歴 |
| 提供機能（管理） | カレンダーによるスケジュール管理、予約・顧客・メニュー管理、定期予約のイレギュラー対応、売上レポート |
| カレンダー | 独自DBを正としてGoogleカレンダーと双方向同期 |
| 決済 | 現金・銀行振込（システムは金額提示と入金記録まで）。オンライン決済は将来対応 |

現在のステータス: **要件定義フェーズ**
