# reservation-system

お掃除の家事代行・片付けコンサル向け、LINE公式アカウント連携の予約システム。

## ドキュメント

- [要件定義書](docs/requirements.md)

## 概要

| 項目 | 内容 |
|---|---|
| 顧客インターフェース | LINE公式アカウント（リッチメニュー + LIFF） |
| サービス提供形態 | 訪問（お掃除・片付けコンサル）とオンライン（片付けコンサル）の2形態。形態に応じて必要な顧客情報・移動時間・通知内容が分岐する |
| 提供機能（顧客） | 予約・変更・キャンセル、定期利用の登録／変更／スキップ／解約、予約履歴 |
| 提供機能（管理） | カレンダーによるスケジュール管理、予約・顧客・メニュー管理、定期予約のイレギュラー対応、売上レポート |
| カレンダー | 独自DBを正としてGoogleカレンダーと双方向同期 |
| 決済 | 現金・銀行振込（システムは金額提示と入金記録・消込まで）。オンライン決済は将来対応 |
| 会計・インボイス | 適格請求書・領収書の自動発行とLINE送付、売上の自動仕訳、経費と証憑の管理（電子帳簿保存法対応）、計算書類4表の出力。**申告書の作成と提出は対象外**（税理士の独占業務） |

現在のステータス: **要件定義フェーズ**
