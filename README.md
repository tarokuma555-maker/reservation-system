# reservation-system

お掃除の家事代行・片付けコンサル向け、LINE公式アカウント連携の予約システム。

- [要件定義書](docs/requirements.md)
- **動くデモが入っています**（下記「デモの動かし方」）

## 概要

| 項目 | 内容 |
|---|---|
| 顧客インターフェース | LINE公式アカウント（リッチメニュー + LIFF） |
| サービス提供形態 | 訪問（お掃除・片付けコンサル）とオンライン（片付けコンサル）の2形態。形態に応じて必要な顧客情報・移動時間・通知内容が分岐する |
| 提供機能（顧客） | 予約・変更・キャンセル、定期利用の登録／変更／スキップ／解約、予約履歴、領収書の確認 |
| 提供機能（管理） | カレンダーによるスケジュール管理、予約・顧客・メニュー管理、定期予約のイレギュラー対応、インボイス発行、各種設定 |
| カレンダー | 独自DBを正としてGoogleカレンダーと双方向同期（本実装で対応） |
| 決済 | 現金・銀行振込（システムは金額提示と入金記録・消込まで）。オンライン決済は将来対応 |
| 会計・インボイス | 適格請求書・領収書の発行とLINE送付、売上の自動仕訳、経費と証憑の管理（電子帳簿保存法対応）、計算書類4表の出力。**申告書の作成と提出は対象外**（税理士の独占業務） |

## デモの動かし方

Node.js 20以上が必要です。

```bash
npm install
npm run db:reset   # SQLiteのDBを作り、デモデータを投入する
npm run dev        # http://localhost:3000
```

ブラウザで <http://localhost:3000> を開くと、以下の2つに分かれています。

| 入口 | 内容 |
|---|---|
| `/liff` | **お客様側**（LINEのトーク画面とリッチメニューを再現） |
| `/admin` | **管理画面**（スケジュール・定期予約・顧客・メニュー・請求書・設定） |

お客様側の画面上部にある黒いバーで、**操作するお客様を切り替えられます**。
本番ではLIFFがLINEユーザーIDを取得しますが、デモでは切替で代用しています。

### 切り替えて試せる4名

| お客様 | 特徴 | 確認できること |
|---|---|---|
| 佐藤 美咲 | 世田谷区・2LDK・定期利用中 | 訪問予約、定期のスキップ、領収書 |
| 山田 健一 | 目黒区・3LDK以上・ペットあり | 間取りによる所要時間の補正（+60分） |
| 小林 あかり | **住所の登録なし（遠方）** | 訪問メニューがエリア外で選べず、オンラインへ誘導される |
| 株式会社みらいオフィス | **法人・登録番号あり** | インボイスの宛名が法人名になる |

### デモで確認できること

1. **提供形態で分岐する予約フロー** — 訪問とオンラインで、必要な情報も空き枠の出方も変わる
2. **移動時間バッファの4パターン** — 前後の予約の組み合わせで必要時間を計算。埋まっている枠にマウスを乗せると理由が出る
3. **定期予約のイレギュラー対応** — 「今回だけ休む」「今回だけ日時変更」をしてもルール変更で消えない
4. **適格請求書（インボイス）の発行** — 税率ごとに1回だけの端数処理、法定6項目の検証、発行時点のスナップショット保存

### 設定値はすべて仮置き

料金・営業時間・移動バッファ・登録番号・対応エリアなどは仮の値です。
`/admin/settings` からその場で変更でき、空き枠の計算や書類の表示にすぐ反映されます。

## 構成

```
src/
  lib/
    availability.ts  空き枠の計算（提供形態別の移動バッファを含む）
    recurring.ts     定期ルールの展開と、個別変更を保護した再生成
    tax.ts           消費税の計算（税率ごとに1回だけ端数処理）
    invoice.ts       適格請求書の発行・無効化・返還・修正
    settings.ts      仮置きの設定値と、その保存
    time.ts          日本時間の取り扱い
  app/
    liff/            お客様側（LINE内で開く画面）
    admin/           管理画面
    api/slots/       空き枠を返すAPI
    actions.ts       予約・定期・請求書の更新処理
prisma/
  schema.prisma      データモデル
  seed.ts            デモデータ
tests/               自動テスト
scripts/smoke.ts     ブラウザでの動作確認
```

### デモ実装と本実装の違い

| 項目 | デモ | 本実装 |
|---|---|---|
| データベース | SQLite（追加のインフラなしで動くため） | PostgreSQL |
| LINE連携 | 画面の再現のみ。通知は送らない | Messaging API・LIFF・リッチメニュー |
| Googleカレンダー | 未接続（ブロック枠は手動登録） | 双方向同期、Meet URLの自動発行 |
| 請求書PDF | 画面表示まで | PDF生成とLINEへの自動送付 |
| 会計 | 請求書の発行と検証まで | 仕訳の自動生成、証憑管理、決算書の出力 |
